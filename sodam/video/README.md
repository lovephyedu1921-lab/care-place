# 소담한방병원 홍보영상 시안 v0.1 (60초, 1920×1080)

결과물은 `out/sodam-promo-60s-draft.mp4` 입니다. 기획안(`../promo-video-plan.md`)의 컨셉 A 스토리보드 9개 장면을 모션그래픽으로 옮겼습니다.

| 시간 | 장면 |
|---|---|
| 0~4초 | 영일대 일출 |
| 4~9초 | 통증은 일상을 멈추게 합니다 |
| 9~14초 | 장성동 소담한방병원 외관 |
| 14~20초 | 먼저, 충분히 듣습니다 (상담) |
| 20~32초 | 침 · 추나 · 도수치료 · 한약 |
| 32~40초 | 편안한 입원 치료 |
| 40~45초 | 원장 한마디 |
| 45~53초 | 다시, 나의 일상으로 |
| 53~60초 | 엔딩 (로고, 연락처) |

## 시안의 한계
- 내레이션은 아직 없습니다. 자막과 배경음악으로만 구성했습니다. 성우 녹음이나 AI 음성을 입히면 기획안의 내레이션 원고를 그대로 쓸 수 있습니다.
- 대표전화 `054-000-0000`은 임시 번호입니다. 진료시간도 병원 확인이 필요합니다.
- 로고는 시안용으로 새로 그린 심볼(그릇에 담긴 새싹 = '소담하게 담다')입니다. 병원 로고 파일을 받으면 교체합니다.
- 배경음악은 코드로 직접 합성한 음원이라 저작권 문제가 없습니다.

## 다시 만들기
```bash
./build.sh          # 한지 텍스처 → 프레임 렌더(Playwright) → 음악 합성 → mp4
```
- `index.html`: 영상 원본. 브라우저로 열면 실시간으로 재생됩니다.
- `render.cjs`: 프레임 캡처, `make_music.py`: 배경음악, `make_hanji.py`: 한지 텍스처
- 문구나 전화번호는 `index.html`에서 고친 뒤 `./build.sh`를 다시 실행하면 됩니다.
