배경음악: 소담 주제곡 `../reels2/audio/bgm-korean-fusion-2.mp3`

내용 출처: 사용자가 제공한 광양자 치료 설명(채혈 → UV-C 254nm·의료용 산소 처리 → 정맥 재주입, 1회 약 1시간, 주 1회 5~10회, 주의사항).
소담 홈페이지에는 이 치료가 나오지 않으므로, 병원에서 실제로 시행하는지와 채혈량·횟수를 공개 전에 확인해야 합니다.

| 시간 | 장면 |
|---|---|
| 0~3.5초 | 내 혈액에 빛과 산소를 더하는 치료 |
| 3.5~7초 | 광양자 치료(포톤 테라피)란? 혈액 + 자외선 + 산소 |
| 7~10.5초 | 01 몸 밖에서 처리하고 다시 몸 안으로 (① 채혈 → ② 빛·산소 → ③ 재주입 순환 애니메이션) |
| 10.5~14초 | 02 특수 자외선 UV-C(254nm)와 의료용 산소 (빛 아래를 지나는 혈액 애니메이션) |
| 14~17.5초 | 03 1회 약 1시간 진행 과정 (채혈 약 80~120cc → 자외선·산소 처리 → 정맥 재주입) |
| 17.5~21초 | 04 이런 관리에 활용됩니다: 혈액순환·대사 / 면역·항산화 / 만성 피로 회복 / 암 회복기 보조 |
| 21~24.5초 | 05 보통 주 1회, 5~10회 · 횟수와 간격은 의료진이 결정 |
| 24.5~27.5초 | 꼭 알아두세요: 드문 합병증(감염·출혈·혈관 손상) / 표준치료를 대신하지 않음 / 전문의 상담 후 결정 |
| 27.5~32초 | 광양자 치료(UBI) · 054) 727.2550 · @sodamhb |

의료광고 주의: "노폐물·독소 분해", "혈압·고지혈증 관리" 같은 효과 단정 표현은 넣지 않았고, 활용 분야는 "활용됩니다"로만 표현했습니다. 혈액을 다루는 시술이라 부작용·주의사항 장면을 넣었습니다.
