> "전신을 감싸는 돔 형태의 광·온열 케어 장비로, 원적외선 기반 열 자극을 통해 체온 상승과 순환 개선을 목표로 합니다. 편안한 누운 자세로 전신 릴랙스와 컨디션 회복을 도와줍니다."
