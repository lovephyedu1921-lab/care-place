## 0. 한 줄 요약 (엘리베이터 피치)

**카메라 1대·5분으로 오십견(어깨) 상태를 Grade 0–4로 수치화하는 비의료 스크리닝 SaaS.
일본 온천·스파 등 오프라인 웰니스 거점(연 40만 방문)에 넣어 광고비 0(Zero CAC)으로
프리시니어(40–60세) 데이터를 모으고, 거점 구독료 + B2C 리포트·커머스 + 데이터 라이선스로 수익화한다.**

- 설립 1년 만에 **일본 정기구독 계약 확정('26.07)** + **R&D(디딤돌) 선정** 동시 달성
- 데모 후 **4개월 만에 첫 수출 입금**(60만 엔, '26.06)
- 실사용자(n=49) **유료 지불의사 95%**

### 핵심 카피 (그대로 재사용 가능한 문장)

## 5. Solution & Product

- **B2B(거점)**: 이미 모인 트래픽을 추가 매출로 전환하는 거점 SaaS
- **B2C(프리시니어)**: 카메라 1대·5분, 어깨 상태를 **Grade 0–4**로 등급화하는 비의료 스크리닝
- 확장: 오십견 측정 → 종합 건강정보 → 맞춤 커머스 (O2O 전환)

### 사용자 여정 (온천 방문 시)
1. **POINT 01 – 입장 후 로비에서 셀프 측정** (영업비용 0원)
   - ROM·비대칭: 외회전/내회전/외전
   - 문진: 통증 지속시간·근력·통증 형태·통증 강도·경직도
   - 오십견 위험도 즉석 스코어링 (예: 68점), 약 1분 / 문진 입력하며 회원가입 완료
2. **POINT 02 – 나오면서 문진 체크 → 앱 온보딩** (QR 스캔 → 앱 설치, 자연스러운 락인)
3. **POINT 03 – 실물 건강 리포트 & 맞춤 커머스**
   - AI 리포트 유료과금, 오십견 맞춤 추천 (예: 어깨 온열밴드 ₩39,000)
   - 온열·영양제 맞춤 커머스로 ARPU 발생

### 기술
- **VIBE-Motion (측정) × AC-AMS (판정)**
  - AC-AMS = *Adhesive Capsulitis Assessment & Management System*
  - 통증의 '감' 대신 정성×정량 복합지표로 등급화, 하이브리드 판정(Grade 0~4, 전문의 판정에 준함)
- 검증 로드맵 목표: **85% / 0.75 / ≤10°** (⚠ 각각 정확도 / 상관·일치도 계수 / ROM 오차로 추정) — 디딤돌 2억 과제로 고도화 중
- 데이터 파이프라인
  - **L0 수집**: 싱글카메라 모션(ROM), 자가문진(AI Agent), 인바디 체성분, 키오스크·앱, 거점 데이터(멤버십·결제/POS·CRM)
  - **L1 정제**: AC-AMS CORE, 전처리·Vision, 표준화·Schema, JSON 정규화 (비정형 오프라인 → 정형)
  - **L2 판단 AI**: Rule-base + LLM + RAG
  - **L3 데이터 자산**: 한·일 시계열 코어 DB (축적될수록 해자↑)
  - **L4 가치**: B2C 유저 / B2B 거점 / B2B Data Licensing
- **Data Flywheel**: 사용·과금·재방문 로그 → 데이터 자산 축적 → 복제 불가 해자

## 7. Business Model

**B2B2C 이중 채널(앱 × 키오스크)**로 데이터 수집, 자금은 자사 허브로 순환.

| 채널 | 역할 | LTV/매출 근거 |
|------|------|---------------|
| B2B MAIN (거점사업자) | Cash-cow | 1,350만 + 월 90~120만 × 24~60개월 + 업셀 = **3,510만 → 8,550만 원+** |
| B2B SUB (광고·리서치) | Scale-up Engine | 연간계약 200~500만 원, 데이터 API 라이선스 연 5천만~1억+ |
| B2C (프리시니어) | Data Engine | LOW 0원 / HIGH 리포트 1만×3 + 영양제 2만×12 = 연 27만 원+ |

## 10. 발표자료 제작 시 활용 가이드

**이 덱에서 배울 IR 장표 패턴**
1. **질문형 헤드라인** — 투자자가 물을 질문을 먼저 던지고 장표가 답한다.
2. **숫자 하나 크게** — 95%, 4개월, 40만, 555만, 8,550만 원 같은 단일 숫자를 앵커로.
3. **"A가 아닌 B" 대비 문장** — '설문'이 아닌 '실사용', '검토'가 아닌 '지불', '예방'이 아닌 '지금 아픈'.
4. **3중 검증 구조** — 사용자 / 고객사 / 시장의 목소리로 수요를 교차 검증.
5. **시장 진화 3단계 프레임** — 1.0(과거) → 2.0(실패) → 3.0(지금, 우리).
6. **FACT vs PROJECTION 분리** — 확정 실적(입금 기준)과 계획을 시각적으로 구분.
7. **출처 각주 필수** — 모든 통계 장표 하단에 출처 명시.
8. **감성 클로징** — "인생의 오후 1시" 은유로 브랜드 미션 마무리.

**재사용 시 주의**
- 통계 출처는 HIRA·국민건강보험공단(2018~2022), 일본 환경성·후생노동성 등. 외부 발표에 쓸 땐 원 출처 재확인 권장.
- 원화 환산은 약 9.16원/엔 기준(500만 엔 ≈ 4,580만 원), 환율 변동 가능.
- ⚠ 표시 항목은 원문 파편화로 맥락이 불확실함.
